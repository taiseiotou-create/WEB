    わたしについて

    About

    鹿児島を拠点に活動するグラフィックデザイナー／アートディレクターです。 広告代理店とマイナビで、求人誌、新聞広告、ポスター、Web、テレビ・ラジオCMの企画制作に携わってきました。 現在はフリーランスとして、アイドマ・ムスビなどの制作に参加しながら、紙の販促物からWebサイト、ランディングページ、採用広告まで制作しています。 自主制作では、HSVCJ関連のサイトや「てんぷれや」のサイトなど、AIも活用しながらWebサイトづくりに取り組んでいます。

    Career
    広告代理店（グループ会社）でデザイナー、アートディレクター、バイスマネージャーを担当し、最大7人のチームの指導・育成を経験。マイナビで紙媒体の制作に従事。現在フリーランスとして、アイドマ・ムスビなどの制作に参加
    Approach
    「誰に、何を、どう感じてほしいか」を言葉にしてから形にします。コピーと構成を先に固めることで、紙でもWebでもぶれないデザインをつくります
    Services
    広告・販促物 / パンフレット・冊子 / ロゴ / Webサイト・LPの構成とデザイン / コピー・企画書 / 制作進行
    Tools
    Illustrator / Photoshop / InDesign / Figma / WordPress / STUDIO / Shopify / BASE / Keynote / Canva
    AI
    ChatGPT・Claude・画像生成を、企画の検討や試作に活用
    Award
    広告代理店時代に、チームとして広告賞を受賞（詳しくは「実務の実績」に掲載）
